# Hex Softwares - Python Programming Internship Projects

Hi! My name is **Kuldeep Singh** and this repository contains the Python projects developed during my internship at **Hex Softwares**. These projects demonstrate various Python concepts ranging from simple logic programming to using complex libraries like `SpeechRecognition` and text-to-speech.

---

## 📂 Project Overview

### 1. Fibonacci Sequence Generator (`project 1 intern/`)
A simple Python program designed to generate the Fibonacci series up to a custom number of terms specified by the user. 
- **Learning Outcome:** Understanding loops, logic building, and user input validation.
- **How to run:**
  ```bash
  cd "project 1 intern"
  python fibonacci_generator.py
  ```

### 2. Custom Voice Assistant (`project 2 intern/`)
A fully-functional digital voice assistant capable of listening to user audio using the microphone, interpreting speech into text, and verbally replying to commands.
- **Features Include:**
  - Checking the current time.
  - Doing live Wikipedia searches.
  - Opening browsers (Google, YouTube).
  - Translating spoken English directly into **Hindi Text**. 
- **Libraries used:** `SpeechRecognition`, `pyttsx3`, `deep-translator`, `wikipedia`
- **How to run:**
  ```bash
  cd "project 2 intern"
  pip install -r requirements.txt
  python voice_assistant.py
  ```

### 3. Tic-Tac-Toe vs Computer (`project 3 intern/`)
A command-line based Tic-Tac-Toe game where the user plays directly against an automated computer opponent.
- **Learning Outcome:** Matrix indexing, game logic/win conditions, and using Python's `random` library for autonomous moves.
- **How to run:**
  ```bash
  cd "project 3 intern"
  python tic_tac_toe.py
  ```
